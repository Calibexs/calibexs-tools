# Calibexs Tools

A collection of browser-based utilities for networking, security, encoding, hashing, passwords, and general technical use.

Live site: https://tools.calibexs.com/

## Features

- CIDR / subnet tools
- IP and network utilities
- Password generator
- Encoding and decoding tools
- Hashing utilities
- Text conversion helpers
- Lightweight browser-only tools
- Responsive Calibexs interface

## Project Structure

- index.html — complete frontend and tool logic

## Privacy

The tools run locally in the browser unless otherwise stated.

This repository contains only the public frontend. Server configuration, credentials, private IP addresses, keys, certificates, and internal infrastructure files are not included.

The live deployment uses shared Calibexs theme assets from the server, which are intentionally excluded from this repository.
